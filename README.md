# Flask SQLAlchemy Relationships Lab

This is a Flask web application designed to practice and implement database models and relationships using SQLAlchemy and Flask-Migrate.

## Project Structure

```text
flask-sqlalchemy-relationships-lab/
│
└── server/
    ├── app.py              # Flask application routes
    ├── models.py           # SQLAlchemy models and relationships
    ├── seed.py             # Database seeding script
    ├── conftest.py         # Pytest configuration
    └── testing/            # Test suite directory
